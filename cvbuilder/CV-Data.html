Sync edits between laptops

When sync is on, every Save also writes your edits to in your GitHub repository. When you open this page on another laptop, it loads them from there.

Do this once on each laptop:

  1. Open GitHub → New fine-grained token.
  2. Under Repository access, choose Only select repositories and select .
  3. Under Permissions → Contents, choose Read and write. Generate the token and copy it.

The token is saved only in this browser. It is never added to the page or to the repository.
